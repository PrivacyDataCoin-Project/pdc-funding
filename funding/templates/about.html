How funding works

Same idea as classic CryptoNote community FFS: propose work, raise PDC into escrow, deliver milestones, receive payouts. Wallet layer follows the PDC tipbot pattern (integrated addresses + payment_id) — not Monero subaccounts.

Flow

  1. Proposal — author submits scope, target, milestones.
  2. Funding — admin opens funding; donors send PDC to the proposal’s integrated address.
  3. WIP — work proceeds; comments track updates.
  4. Payout — admin releases escrow to the author’s address per milestone.
  5. Completed — archive for the community.

Trust model

Escrow is custodial (operator hot wallet). Prefer a thin wallet and clear admin accountability. Prices come from Trade /api/prices/usd (oracle when enabled).
